# Terminal note: project archived on the evidence

> Source: author decision on review recommendation, 2026-09-20
> Collected: 2026-09-20
> Published: 2026-09-20

## The four statements

1. The original goal — usable long-range addressable memory in an
   online byte-level recurrent model — was NOT achieved.
2. Retention/storage is possible (slow channels self-built, linear
   probes 10x chance, one-episode memorization exact); retrieval /
   addressing was not, under any tested substrate (trunk state,
   state anchors, fast weights, BPTT credit, aux pressure, span
   supervision, true external store — the last failing below chance).
3. The engineering artifacts are preserved and green: 128-test
   suite with frozen eval contract, memorization gate, causality /
   addressing / recall probes, RTRL implementation with oracles,
   Dream-RSI loop (parked, gated), three pinned bug classes
   (opt-ownership, stale-graph, assertion-first).
4. The project is closed on the evidence. No further experiments
   in this family; any future work starts from the fork with new
   boxes, not from residual optimism.
