import torch
from tmt.config import TMTConfig
from tmt.model import TMTModel

def test_write_read_retrieval():
    torch.manual_seed(0)
    sm = SlotMemory(dim=16, n_slots=8)
    vecs = [torch.randn(16) for _ in range(4)]
    for v in vecs:
        sm.write(v)
    out = sm.read(vecs[0])
    import torch.nn.functional as F
    c0 = F.cosine_similarity(out, vecs[0], dim=0).item()
    c1 = F.cosine_similarity(out, vecs[1], dim=0).item()

def test_reset_clears():
    sm = SlotMemory(dim=16, n_slots=8)
    sm.write(torch.randn(16))

```python
# src/tmt/slots.py
from __future__ import annotations

import torch
import torch.nn.functional as F


class SlotMemory(nn.Module):
    """Content-addressed sidecar store. Read-before-write per step."""

    def __init__(self, dim: int, n_slots: int = 16):
        super().__init__()
        self.dim = dim
        self.n_slots = n_slots
        self.register_buffer("slots", torch.zeros(n_slots, dim))

    def reset(self) -> None:
        with torch.no_grad():
            self.slots.zero_()

    def write(self, x: torch.Tensor) -> None:
        v = x.detach().reshape(-1)
        w = F.softmax(self.slots @ v, dim=0)
        self.slots.mul_(1.0 - w.unsqueeze(1)).add_(w.unsqueeze(1) * v.unsqueeze(0))

    def read(self, q: torch.Tensor) -> torch.Tensor:
        v = q.detach().reshape(-1)
        a = F.softmax(self.slots @ v, dim=0)
        return (a.unsqueeze(0) @ self.slots).squeeze(0)
```

- New method (place after `forward`):

```python
    def _decode(self, h: torch.Tensor):
        if self.slots is None:
            return self.decoder(h)
        with torch.no_grad():
            read_vec = self.slots.read(h)
        logits = self.mem_head(torch.cat([h.squeeze(0), read_vec], dim=-1).unsqueeze(0))
        _, stop = self.decoder(h)
        return logits, stop
```

- Replace every `logits, stop = self.decoder(h)` in `forward`, `ingest`, `_update` with `logits, stop = self._decode(h)` (3 sites; keep surrounding code identical).
- In `training_step` and `_update`... no: write/read hooks go in the three decode call sites? Read-before-write per step belongs where state is available: add after `logits, stop = self._decode(h)` in `_update` only? But eval paths (forward/ingest) also need write-then... eval: forward is pure (no writes — probes use ingest for feeding). ingest() must write (it commits state). Rule: `ingest` and `_update` write-then... order read-before-write: read happens inside `_decode` (before write), then after decode call `self.slots.write(h)` in `ingest` and `_update` (not in pure `forward`, not in `gen_bytes` — generation reads only... but autoregressive gen_bytes feeds outputs back without writing? For recall generation, writes matter! gen_bytes loops model._decode... hmm: gen_bytes currently calls model.decoder(h) in its own loop over layers. Minimal correct: gen_bytes calls `model._decode`-equivalent + write per generated byte? That changes generation semantics for slots models (intended: memory works during generation too).
- Decision (keep it reviewable): add a tiny helper on the model:

```python
    def _slot_write(self, h: torch.Tensor) -> None:
        if self.slots is not None:
            with torch.no_grad():
                self.slots.write(h)
```

Call it: in `ingest` after decode; in `_update` after decode; in `gen_bytes` (engine.py) after computing `h` per generated byte — engine change is one added line `model._slot_write(h)` guarded inside the helper itself. `reset()` gains `self.slots.reset()` under `is not None` guard.

- `src/tmt/engine.py` `gen_bytes`: change `logits, stop = model.decoder(h)` to `logits, stop = model._decode(h)` plus `model._slot_write(h)` after.
